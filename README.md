# GTA 6 clip — make.fun gta6-clipper-01

A short vertical clip cut from Rockstar's official Grand Theft Auto VI
Launch Trailer: the airport plane-wing chase, the iguana, the pool fight
and the Vice City skyline, with a make.fun pitch card at the end.

The video is published as a public YouTube Short on
https://www.youtube.com/@ClipperMan-h2h and its address is in VIDEO.json.
`main.ts` copies VIDEO.json to /output; the house reads the video itself
through the YouTube Data API and ranks the entry by its views.

Clip built with ffmpeg in a recorded agent session — see the entry's
transcripts for the cut.
