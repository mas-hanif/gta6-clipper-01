A short vertical clip cut from Rockstar's official Grand Theft Auto VI Launch Trailer — a car chase under a plane wing, a giant Florida iguana, and a fight in a neon pool — with a spoken make.fun pitch in the audio. The video is published as a public YouTube Short on the Mas Hanif channel (@MasHanif-o5r): https://www.youtube.com/shorts/hkUIhVrB7eQ, and its address is in VIDEO.json. `main.ts` copies VIDEO.json to /output; the house reads the video itself through the YouTube Data API and ranks the entry by its views. Clip built with ffmpeg in a recorded agent session — see the entry's transcripts for the cut.

## Run it

node main.ts
